Question 1(b): The CSS Box Model (4 Marks)

Every HTML element rendered in a browser is treated as a rectangular box consisting of four concentric layers: Content, Padding, Border, and Margin.

How Each Component Affects an E-Commerce Product Card

  • 1. Content: The innermost area where actual product information—such as the product photo, item name, price tag, and "Add to Cart" button—is displayed. Its dimensions are controlled by width and height.
  • 2. Padding: The transparent inner cushion between the content and the card's border. It prevents product text and images from touching the card edges, improving readability and visual appeal.
  • 3. Border: The visible line surrounding the padding and content. It visually defines the boundary of each product card (e.g., a 3px solid outline) so shoppers can distinguish individual items.
  • 4. Margin: The transparent outer space outside the border. It separates neighboring product cards from one another in a catalog grid so they do not collide or look cluttered.
